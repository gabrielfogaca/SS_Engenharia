# Sabrina Schreiber Engenharia & Arquitetura

Website profissional, minimalista e moderno para a empresa Sabrina Schreiber Engenharia & Arquitetura.

## ✨ Características

- **Design Minimalista**: Layout limpo e profissional com foco na experiência do usuário
- **Responsivo**: Totalmente adaptável para desktop, tablet e mobile
- **Animações Suaves**: Transições e animações elegantes usando Motion
- **Performance**: Otimizado para carregamento rápido e SEO
- **Acessibilidade**: Componentes acessíveis e semânticos

## 🎨 Seções

1. **Hero** - Introdução impactante com chamada para ação
2. **Sobre** - Apresentação da empresa e valores
3. **Estatísticas** - Números e conquistas
4. **Serviços** - Portfólio completo de serviços oferecidos
5. **Projetos** - Galeria de projetos realizados
6. **Contato** - Formulário de contato e informações
7. **CTA** - Chamada final para ação

## 🛠️ Tecnologias

- **React 18** - Framework principal
- **TypeScript** - Tipagem estática
- **Tailwind CSS 4** - Estilização
- **Motion** - Animações
- **Lucide React** - Ícones
- **Vite** - Build tool

## 🚀 Como usar

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`
4. Build para produção: `npm run build`

## 📝 Personalização

Para personalizar o website para sua empresa:

1. **Imagens**: Substitua as URLs do Unsplash pelas suas próprias imagens
2. **Textos**: Atualize os textos em cada componente
3. **Cores**: Modifique as cores em `/src/styles/theme.css`
4. **Contato**: Atualize as informações de contato no componente `Contact.tsx`
5. **Redes Sociais**: Atualize os links no componente `Footer.tsx`

## 📱 Responsividade

O website é totalmente responsivo e otimizado para:
- Mobile (< 640px)
- Tablet (640px - 1024px)
- Desktop (> 1024px)

## 🎯 SEO e Performance

- HTML semântico
- Scroll suave
- Imagens otimizadas
- Lazy loading
- Meta tags apropriadas
